# Состояние проекта (5 ноября 2026)

Этот файл — для продолжения работы в новой сессии или на другом компьютере. Прочитай его вместе с `CLAUDE.md`, `README.md` и `docs/TZ.md`.

## Что сделано
Все 7 этапов ТЗ (раздел 10) и доработки сверх них:

1. Перенос прототипа на Vite + TypeScript, данные в `public/data`, иконки в `public/icons`, ежедневная выгрузка OpenDota (GitHub Actions → ветка `data`), деплой на GitHub Pages, CI.
2. «Мои герои» (Steam ID, профиль OpenDota, бонус за личный винрейт, звёздочки), «Что купить» (метки угроз для всех 127 героев), ссылка на драфт.
3. Карточка героя (`/hero/pudge`), «Моя линия».
4. Мета: тир-лист S/A/B/C, тренд за 7 дней (по ежедневным снимкам), «Что изменилось в патче» (`public/data/patch.json`).
5. Разбор матча (`/match/{id}`), ожидание разбора OpenDota, 3–6 выводов «факт + совет».
6. Стрим: оверлей для OBS (`/overlay/`), голосование чата Twitch `!1/!2/!3`, викторина; бэкенд `worker/` (Cloudflare) — комнаты для другого устройства, страница голосования зрителей (`/vote/`), таблица лидеров.
7. PWA (установка, офлайн), компактный режим для телефона, горячие клавиши.

Сверх ТЗ: анимации «как в игре» для всех 30 фишек (`src/anim/game.ts`, `src/anim/scenes-game*.ts`), аудит доступности (axe), сайт одним файлом (`npm run standalone` → `kontrpik.html`).

Проверки: 66 тестов Vitest, 59 e2e Playwright (1440 и 400 px, RU/EN). Соответствие критериям приёмки — `docs/ACCEPTANCE.md`.

## Что не сделано и почему
- **Сайт не опубликован.** Нужен репозиторий GitHub владельца (см. «Как продолжить»).
- **Бэкенд стрима не развёрнут.** Нужен аккаунт Cloudflare: секреты `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, переменные `SITE_ORIGIN`, `ROOM_API_URL` (подробно в `README.md`).
- **Не проверено вживую** (из среды разработки были закрыты OpenDota, Twitch, Valve CDN, Cloudflare): выгрузка данных в Actions, «Мои герои» на реальном Steam ID, разбор свежего матча, чат Twitch, оверлей в OBS, иконки способностей и предметов в анимациях (пути на CDN Valve взяты по памяти — часть может не найтись, тогда рисуется плашка).

## Ждёт решения автора
- Бонус за личный винрейт: +0,3 п.п. за каждый процент выше 50%, максимум +3 (`src/player.ts`).
- Тир-лист: S — 10%, A — 25%, B — 35%, C — остальные; вес доли пиков 0,15 (`src/meta.ts`).
- Метки угроз и предметы против них (`src/items.ts`), у Kez, Largo, Ring Master — пусто.
- Список изменений патча 7.41 (`public/data/patch.json`) — сверить с официальными заметками.

## Как продолжить на другом компьютере
1. Распаковать `kontrpik-full.zip` (в нём вся история git).
2. Выложить на GitHub:
   ```bash
   cd kontrpik
   git remote add origin https://github.com/<логин>/kontrpik.git
   git push -u origin main
   ```
3. В репозитории: Settings → Pages → Source: GitHub Actions; Actions → Data → Run workflow.
4. Для работы с Claude Code: открыть claude.ai/code, создать сессию с этим репозиторием и написать «Прочитай docs/STATUS.md и продолжай».

Локально: `npm install`, `npm run dev` (сайт), `npm test`, `npm run e2e`, `npm run standalone` (один файл).
