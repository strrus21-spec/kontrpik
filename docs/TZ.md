# ТЗ: веб-приложение «Контрпик» для Dota 2

Версия 2, 5 ноября 2026. Описывает работающий прототип (`prototype/index.html`) и всё, что нужно добавить. Пункты с пометкой **[готово в прототипе]** перенести без изменений поведения и вида.

---

## 1. Цель и аудитория

Помочь игроку Dota 2 за 30 секунд драфта выбрать героя против вражеского пика, понять, что покупать и как играть, и узнать неочевидные фишки. Аудитория — игроки любого ранга, прежде всего русскоязычные (СНГ), плюс англоязычные. Также контент для Twitch-канала автора (FINIK).

Конкуренты (Dotabuff App, DotaPlus, Dota Coach) — англоязычные, часто платные, работают как оверлей Overwolf. Наше отличие: бесплатный сайт без установки, русский язык, понятные объяснения, фишки с анимациями.

## 3. Что уже есть [готово в прототипе]

### 3.1. Драфт в стиле клиента Dota
- Сверху экран пика: слева **Силы Света** (союзники, до 4 + слот «ТЫ»), по центру золотой **VS** и баны, справа **Силы Тьмы** (враги, до 5). Портреты героев в рамках.
- Слот «ТЫ» мерцает лучшим предложенным героем («Earth Spirit?»).
- При первом запуске пример пика: Phantom Assassin, Pudge, Invoker, Axe, Crystal Maiden с пометкой «пример пика».

### 3.2. Пул героев
Режим **Враг / Союзник / Бан**, поиск (англ. имя или русское прозвище), группы по атрибутам с цветами (сила, ловкость, интеллект, универсальные), подсветка выбранных.

### 3.3. Рекомендации
- Источник статистики (5 вариантов из таблицы выше) и фильтр **Pos 1–5** (цветные чипы).
- **Пьедестал топ-3**: золото, серебро, бронза; оценка словами (Отличный выбор ≥ 6, Хороший ≥ 3, Нормально ≥ 0, Не советую < 0); фраза «Сильнее всего против X и Y. Осторожно с Z.»; полоски матчапов по каждому врагу и союзнику (зелёная вправо, красная влево).
- Места 4–15 компактным списком с пояснением.
- Метки позиций у героя («Pos 2», «Pos 4 Pos 5»).
- **Кого банить**: 5 героев, сильнейших против моих союзников, клик ставит бан.
- **Как играть против этого пика**: до 3 фишек про выбранных врагов, с анимацией.
- Кнопка «Беру его» добавляет героя в союзники.

### 3.4. Фишки
- 30 коротких конкретных фишек, 7 тем: Линия, Фарм, Карта, Управление, Предметы, Против героев, Драфт. Уровень (Новичок, Средний, Продвинутый), роль, метка **7.41** для изменений патча.
- **Анимированная схема** у каждой фишки (canvas, 4 с, цикл, стиль мини-карты, иконки героев). Рисуются только видимые; при `prefers-reduced-motion` — стоп-кадр. Подписи в анимациях на двух языках.
- **Фишка дня** крупно, кнопка «Знаю», прогресс «Изучено N из 30», «скрыть изученные», фильтры и поиск.

### 3.5. Сохранение
`localStorage`: драфт (героев хранить по имени, не по индексу), режим, источник, позиция, язык, изученные фишки.

## 4. Алгоритм счёта [готово — не менять без согласования]

Таблицы на источник: `solo[x]`, `vs[x][y]`, `with[x][y]` = [игры, победы]. Базовый винрейт `p(x)`.

```
Контр c против e:   E = clamp(p(c) − p(e) + 0.5, 0.05, 0.95)
Синергия c с a:      E = clamp(p(c) + p(a) − 0.5, 0.05, 0.95)
Сглаживание:         W = (победы + K·E) / (игры + K),  K = 25
Преимущество:        (W − E) · 100   — процентные пункты
Счёт = Σ контр по врагам + Σ синергия по союзникам (для про-сцены синергии нет)
```
Позиционный фильтр: герой подходит позиции, если ≥ 15% его про-игр на ней (`data/positions.json`, порядок [pos1..pos5]).

Контрольный пример (данные 31.10–02.11.2026, все ранги, пик PA/Pudge/Invoker/Axe/CM): топ-3 Earth Spirit, Puck, Lifestealer. По позициям: Pos 1 Lifestealer, Ursa, Tiny; Pos 5 Phoenix, Disruptor, Bane. Зафиксировать юнит-тестом на `data/stats.json`.

## 5. Данные

- `data/stats.json` — формат: `heroes [[name, attr, roles, iconDataURI]]`, `n`, `counts`, `pub.{all,low,mid,high}.{vs,with,solo}`, `pro.{vs,solo}`, `from`, `to`, `updated`. Пара (x,y): `[2·(x·n+y)]` игры, `+1` победы. Индексы — герои по алфавиту.
- `data/positions.json` — `{имя: [pos1..pos5 игр]}`.
- `data/tips.json` — фишки: `c` тема, `l` уровень, `r` роль, `p` патч 7.41, `h` герои (для «против этого пика»), `t/d` рус., `te/de` англ.
- Как добывать — `scripts/opendota-queries.md`. Логика агрегации — `prototype/desktop/main.js`.
- В веб-версии иконки вынести файлами `public/icons/{slug}.png`, а не base64.

## 6. Новые функции (этап 2)

Каждая функция — на двух языках, работает на телефоне, не ломает существующее.

### 6.1. «Мои герои» (главный приоритет)
- Поле «Твой Steam ID или ссылка на профиль Dotabuff/OpenDota/Steam». Разбираем Steam32, Steam64 и ссылки.
- Запрос `GET /api/players/{id}` и `/players/{id}/heroes?date=90` (из браузера, OpenDota разрешает CORS). Показываем ник, аватар, ранг, топ-героев.
- **Переключатель «Только мои герои»**: рекомендации из героев, сыгранных ≥ 5 раз за 90 дней. В строке героя — «у тебя N игр, винрейт X%».
- Итоговый счёт в этом режиме: статистический счёт + бонус за личный винрейт (сглаженный, вес согласовать; по умолчанию +0.3 п.п. за каждый процент выше 50%, не больше +3).
- Альтернатива без ID: отметить «свои» героев звёздочкой вручную.
- Закрытый профиль → понятное сообщение: «Профиль закрыт. Включи в Dota: Настройки → Общедоступная история матчей, подожди пару минут и попробуй снова.»
- ID и пул хранятся в `localStorage`.

### 6.2. «Что купить против этого пика»
- Блок под рекомендациями: 4–6 предметов с причиной в одну строку. Пример: «**Monkey King Bar** — у Phantom Assassin уклонение».
- Реализация: таблица `threats` (герой → метки угроз) + таблица `counters` (метка → предметы с причиной). Метки: `evasion`, `invis`, `illusions`, `heal`, `magic_burst`, `silence`, `disable_heavy`, `physical_burst`, `passive_break`, `summons`, `mana_burn`, `pierce_bkb`, `lifesteal`, `push`.
- Учитывать мою позицию: керри — MKB, BKB, Silver Edge; саппорт — Dust, Sentry, Glimmer Cape, Force Staff, Lotus Orb, Spirit Vessel.
- Предметы сверить с патчем 7.41 (Shiva не режет лечение; есть Shawl, Splintmail, Wizard Hat, Crella's Crozier).
- Метки заполнить для всех героев; список согласовать с автором, начать с 40 самых популярных.

### 6.3. Страница героя
- Клик по любому герою (пул, слоты, рекомендации) открывает панель или страницу героя (URL `/hero/pudge`).
- Содержимое: портрет, атрибут, позиции с долями, винрейт по каждой группе рангов, **кого он контрит (топ-8)**, **кто контрит его (топ-8)**, **с кем лучше всего (топ-5)**, фишки с этим героем, что покупать против него (из 6.2).
- Кнопки: «Отметить врагом», «Беру его».

### 6.4. Моя линия
- Когда выбрана моя позиция и есть враги: вероятные соперники на линии по `positions.json` (Pos 1 и 5 против вражеских Pos 3 и 4, Pos 2 против Pos 2, Pos 3 и 4 против Pos 1 и 5).
- Карточка: «Твоя линия: против Axe и Crystal Maiden», оценка (лёгкая, средняя, тяжёлая) по сумме матчапов, 2–3 подсказки (стартовые предметы, «держись за крипами»).

### 6.5. Мета и тир-лист
- Раздел «Мета»: тир-лист S / A / B / C по выбранной группе рангов и позиции. Тир = винрейт со сглаживанием + доля пиков. Сортировка, поиск.
- **Тренд за неделю**: хранить ежедневные снимки `solo` (GitHub Actions пишет `data/history/YYYY-MM-DD.json`), показывать ▲/▼ и изменение винрейта за 7 дней.
- Блок «Что изменилось в патче»: 5–8 главных изменений текущего патча коротко на двух языках, со ссылкой на официальные заметки. Обновлять при выходе патча.

### 6.6. Разбор матча
- Поле «Номер матча» или кнопка «Мои последние игры» (из 6.1).
- Если матч не разобран — `POST /api/request/{id}` и опрос статуса с понятным прогрессом («Матч обрабатывается, обычно 1–3 минуты»).
- Выводы простыми словами, 3–6 штук, только из реальных данных: ластхиты на 10-й минуте против среднего по герою и рангу; смерти и где (вне своих вардов); время ключевых предметов против среднего; вклад в убийства; потерянное золото на смертях; варды для саппортов. Каждый вывод — факт + совет.
- Кнопка «Поделиться разбором» (ссылка).

### 6.7. Для стрима (Twitch FINIK)
- **Оверлей для OBS**: отдельная страница `/overlay` с прозрачным фоном. Показывает вражеский пик и топ-3 контрпика. Управление с основной страницы (тот же браузер через `BroadcastChannel`; для другого устройства — код комнаты через простой realtime-бэкенд, например Supabase или Cloudflare Durable Objects).
- **Голосование зрителей**: стример запускает голосование из 3 вариантов, зрители голосуют командой в чате (`!1`, `!2`, `!3`, бот через Twitch IRC/EventSub) или на странице. Оверлей показывает проценты рядом со статистикой.
- **Викторина** «Угадай контрпик» и «Знаешь ли ты фишку?»: 10 вопросов, генерируются из данных и фишек, таблица лидеров (общая, нужен бэкенд).

### 6.8. Удобство
- **Ссылка на драфт**: `?e=pudge,axe&a=lion&b=…&r=mid&pos=2`, кнопка «Скопировать ссылку».
- **Компактный режим для телефона**: только слоты врагов, поиск и топ-5 крупными кнопками.
- **PWA**: установка как приложение, офлайн на последних загруженных данных (service worker).
- Горячие клавиши на ПК: `/` поиск, `1–5` позиция, `E/A/B` режим.

## 8. Архитектура

```
GitHub Actions (cron раз в сутки) → scripts/build-data.ts → public/data/stats.json, history/, icons/
Хостинг: Cloudflare Pages или Vercel (статический фронтенд)
Браузер: считает всё сам; запросы игрока и матча (6.1, 6.6) — напрямую в OpenDota
Бэкенд нужен только для 6.7 (оверлей с другого устройства, голосование, лидерборд)
```
- Vite + TypeScript, без тяжёлых фреймворков (Preact допустим).
- Модули: `scoring.ts` (раздел 4, чистые функции), `i18n.ts`, `state.ts` (localStorage + URL), `items.ts` (6.2), `player.ts` (6.1), `match.ts` (6.6), `anim/` (сцены фишек), `render/`.
- Тесты: Vitest для `scoring`, `items`, разбора Steam ID, выводов разбора матча; Playwright — скриншоты на 1440 и 400 px в обоих языках.

## 9. Критерии приёмки (выборочно)

1. Всё из раздела 3 работает как в прототипе, в обоих языках.
2. Тест алгоритма на `data/stats.json` даёт контрольный топ из раздела 4.
3. «Мои герои»: открытый профиль → пул и личные винрейты за ≤ 3 с; закрытый → понятное сообщение.
4. «Что купить»: для пика PA, Pudge, Invoker, Axe, CM есть MKB (против PA) и BKB (против магии); каждая причина ссылается на конкретного врага.
5. Ссылка на драфт открывает тот же пик на другом устройстве.
6. Разбор матча работает для разобранного матча и корректно ждёт неразобранного.
7. Оверлей читается поверх игры в OBS на 1920×1080.
8. Сборка данных в Actions ≤ 10 минут; при падении сайт работает на вчерашних данных.

## 10. Этапы

1. **Перенос прототипа** на Vite + TS, данные через Actions, тесты, деплой.
2. **Мои герои + Что купить + Ссылка на драфт** (самая большая польза).
3. **Страница героя + Моя линия.**
4. **Мета и тир-лист + тренды + патч.**
5. **Разбор матча.**
6. **Стрим: оверлей, голосование, викторина** (нужен бэкенд).
7. **PWA, компактный режим, горячие клавиши.**

После каждого этапа — деплой и короткий отчёт.
