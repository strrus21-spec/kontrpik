DotaPick — подготовлено 19 ноября 2026

Название и назначение
  Бренд: DotaPick (сайт https://dotapick.pro)
  Что делает: помогает игрокам Dota 2 выбрать героя против состава врага (контрпик) по статистике реальных
  матчей; показывает мету патча (тир-лист), разбор сыгранного матча по его номеру и сборник игровых приёмов
  («фишек») с анимациями и викториной.
  Для кого: игроки Dota 2 (подростки 13+ и взрослые).

Тип и категория
  Тип: приложение (не игра).
  Предлагаемая категория: «Развлечения» (Entertainment). Альтернатива — «Инструменты» (Tools). Решает издатель.

Пакет и версия
  applicationId: pro.dotapick.app
  Вариант сборки для Google Play: play (без самообновления — обновления только через магазин).
  versionName: 1.1.N, versionCode: N — номер запуска сборки «Google Play» в GitHub Actions (первая сборка: 1).
  Минимальная версия Android: 7.0 (API 24). targetSdk: 36. compileSdk: 36.
  Нативных библиотек нет (только Kotlin/Java + WebView) — требование 64 бит и страниц 16 КБ не затрагивается.

Функции и ограничения
  1. Контрпик: отмечаешь героев врага (и союзников, баны), приложение показывает лучших героев против этого
     состава с процентом преимущества, учитывает позицию (Pos 1–5) и группу рангов; ключевые предметы.
  2. Карточка героя: позиции, винрейт по рангам, кого контрит / кто контрит его, с кем лучше, что собирают.
  3. Мета: тир-лист героев по рангу и позиции, тренд за неделю, что изменилось в патче.
  4. Разбор матча: по номеру матча или Steam ID / ссылке на профиль — данные из открытого API OpenDota.
  5. Фишки: короткие игровые приёмы с анимациями, отметка изученных, викторина.
  6. Для стримеров: комнаты голосования зрителей и оверлей для OBS (анонимные голоса, без текста от зрителей).
  Интернет: нужен для свежей статистики и разбора матчей. Без интернета работает встроенная копия
  (контрпик, мета, фишки — по последней скачанной статистике; разбор новых матчей недоступен).
  Ограничения: статистика обновляется раз в сутки; разбор матча зависит от доступности OpenDota.
