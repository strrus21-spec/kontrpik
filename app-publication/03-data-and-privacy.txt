АККАУНТЫ

ХРАНИТСЯ ТОЛЬКО НА УСТРОЙСТВЕ (не передаётся)
  язык, тема, текущий драфт, «★ Мои» герои, введённый Steam ID, изученные фишки, рекорд викторины,
  список открытых матчей, код комнаты стрима; кэш страниц и картинок для работы без интернета.
  Удаление: очистить данные приложения в настройках Android или удалить приложение.

ПЕРЕДАЁТСЯ С УСТРОЙСТВА — по одной записи на тип данных

1) ID пользователя (Steam ID / ID игрока Dota) — тип Play: «Личная информация → Идентификаторы пользователя»
   Откуда и куда: пользователь вводит сам → открытый API OpenDota (api.opendota.com).
   Зачем: показать его последние игры и разбор матча (функциональность).
   Когда: только после ввода и нажатия «Показать»/«Разобрать».
   Отказ: можно не вводить — остальные функции работают.
   Хранение: у нас не хранится; на устройстве — до очистки данных. OpenDota — внешний сервис, его политика:
   https://www.opendota.com/privacy (НУЖНО ПРОВЕРИТЬ ссылку издателю).
   Передача третьим лицам: по прямому действию пользователя (исключение «инициировано пользователем»).
   Номер матча — публичный идентификатор матча, не персональные данные.

2) Сообщение обратной связи и контакт — «Сообщения → Другие сообщения в приложении», «Личная информация →
   Адрес эл. почты / Другая информация» (если пользователь укажет контакт)
   Откуда и куда: форма «О сайте → Обратная связь» → Web3Forms (api.web3forms.com) → почта автора.
   Зачем: ответ пользователю и исправление ошибок (связь с разработчиком).
   Когда: только при нажатии «Отправить». Контакт — необязательное поле.
   Хранение: в почтовом ящике автора; удаление — по запросу через ту же форму.
   Web3Forms — поставщик услуги (пересылка формы).

3) Голос в комнате стрима и анонимный идентификатор — «Действия в приложении → Другие действия»,
   «Идентификаторы устройства или другие идентификаторы» (случайный ID, создаётся приложением)
   Откуда и куда: зритель голосует в комнате стримера → сервер комнат DotaPick (Cloudflare Workers,
   kontrpik-room.strrus21.workers.dev — сервер автора).
   Зачем: подсчёт голосов (функциональность) и защита от накрутки.
   Когда: только при голосовании/создании комнаты.
   Хранение: голоса — пока существует голосование; IP-адрес — только для ограничения «не больше N голосов
   с одного IP», удаляется при запуске следующего голосования в комнате.
   НУЖНО ПРОВЕРИТЬ издателю: как отметить IP-адрес в анкете (обычно «Идентификаторы устройства…» с целью
   «Предотвращение мошенничества, безопасность»).

4) Технические данные запросов (IP-адрес, User-Agent) — при любой загрузке страниц и картинок:
   хостинг GitHub Pages (dotapick.pro) и CDN изображений Valve (cdn.cloudflare.steamstatic.com).
   Обрабатываются этими сервисами автоматически, приложение их не собирает и не хранит.

НЕ СОБИРАЕТСЯ
  геолокация, контакты, фото/видео, файлы, микрофон, камера, SMS, звонки, платёжные данные, здоровье,
  рекламный ID (AD_ID в манифесте нет — проверяется при сборке AAB, шаг «Проверка манифеста»).

РАЗРЕШЕНИЯ ANDROID
  android.permission.INTERNET — загрузка статистики и страниц.
  android.permission.ACCESS_NETWORK_STATE — понять, есть ли сеть, и показать копию без интернета.
  Других разрешений и фоновых сервисов нет.
  «Поделиться» итогом матча: картинка создаётся только по нажатию и передаётся через стандартное меню
  Android (FileProvider, временный файл в кэше приложения).

БЕЗОПАСНОСТЬ
  Все соединения — HTTPS. Данные не продаются и не передаются для рекламы.
